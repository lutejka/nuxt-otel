The module provides three composables for manual instrumentation in your server routes. They are auto-imported, and the telemetry they create appears in the DevTools UI when devtools are enabled.

## Trace operations with useOtelTracer

`useOtelTracer(namespace)` returns a tracer and a `trace` helper. The helper starts an active span, runs your callback, and ends the span when the callback finishes. Span names use the `namespace.operation` format.

```ts [server/api/checkout.post.ts]
export default defineEventHandler(async () => {
  const { trace } = useOtelTracer('checkout')

  const result = await trace('process-payment', async (span) => {
    span.setAttribute('payment.provider', 'stripe')

    // this runs inside an OpenTelemetry span named "checkout.process-payment"
    const payment = await processPayment()
    return payment
  })

  return result
})
```

The callback receives the active span, so you can add attributes, events, or status information before it ends.

## Emit structured logs with useOtelLogger

`useOtelLogger()` returns an OpenTelemetry logger for emitting structured log records:

```ts [server/api/checkout.post.ts]
export default defineEventHandler(async () => {
  const logger = useOtelLogger()

  logger.emit({
    // 9 = INFO in the OpenTelemetry logs data model
    severityNumber: 9,
    body: 'Payment processed',
    attributes: { amount: 42, currency: 'USD' },
  })
})
```

Logs emitted during a request are correlated with the active trace context, so they appear alongside the related spans in DevTools.

## Record metrics with useOtelMeter

`useOtelMeter(namespace)` returns an OpenTelemetry meter. Use it to create counters, gauges, and histograms:

```ts [server/api/orders.post.ts]
const quantity = useOtelMeter('orders').createHistogram('orders.quantity', {
  description: 'Quantity of items in completed orders',
  unit: '{item}',
})

export default defineEventHandler(async (event) => {
  const body = await readBody(event)
  const order = await placeOrder(body)

  // Histograms are rendered in DevTools as sum / count,
  // so this metric shows the average order quantity.
  quantity.record(body.quantity)

  return order
})
```

`useOtelMeter` works with counters, gauges, and histograms from the [OpenTelemetry metrics API](https://opentelemetry.io/docs/languages/js/instrumentation/#metrics).

## Choose the right signal

| Signal  | Use it for                                              | Composables      |
| ------- | ------------------------------------------------------- | ---------------- |
| Traces  | Request flow, timing, and parent/child relationships    | `useOtelTracer`  |
| Logs    | Discrete events with severity and structured attributes | `useOtelLogger`  |
| Metrics | Aggregated values such as counts, rates, and durations  | `useOtelMeter`   |
