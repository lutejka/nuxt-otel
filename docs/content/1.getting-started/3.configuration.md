Configure the module with `nuxtOtel` options and choose which layers to trace with the top-level `tracingChannel` option.

## Configure module options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lutejka/nuxt-otel'],
  nuxtOtel: {
    // Enable the built-in OpenTelemetry SDK (Node.js presets)
    instrument: true,
    // Enable the OpenTelemetry panel in Vite DevTools
    devtools: true,
  },
})
```

| Option       | Type      | Default | Description                                                              |
| ------------ | --------- | ------- | ------------------------------------------------------------------------ |
| `instrument` | `boolean` | `true`  | Adds a built-in `NodeSDK` (intended for Node.js presets)                 |
| `devtools`   | `boolean` | `true`  | Adds the OpenTelemetry panel to Vite DevTools in development             |

::note
The built-in SDK is Node.js-only. On other Nitro presets, set `instrument: false` and register your own SDK. See [Instrumentation](/guide/instrumentation).
::

## Enable tracing channels

Tracing channels are opt-in. If `tracingChannel` is unset, the module registers no channel hooks and creates no spans.

| Channel     | Default | Minimum Nuxt | What it traces                                      |
| ----------- | ------- | ------------ | --------------------------------------------------- |
| `nuxt`      | `false` | `4.5.0`      | SSR renders, islands, data fetching, and plugins    |
| `h3`        | `false` | `5.0.0`      | HTTP requests handled by h3                         |
| `srvx`      | `false` | `5.0.0`      | Server requests and middleware                      |
| `unstorage` | `false` | `5.0.0`      | Storage operations such as `get`, `set`, and `remove` |

### Enable all channels

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  tracingChannel: true,
})
```

### Enable specific channels

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  tracingChannel: {
    nuxt: true,
    h3: true,
    srvx: false,
    unstorage: false,
  },
})
```

An object enables every channel that is not explicitly set to `false`. Set the channels you do not want to `false` rather than omitting them.

`tracingChannel: false` disables all channels, including the `nuxt.*` channels.
