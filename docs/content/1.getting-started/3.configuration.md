Configure the module with `nuxtOtel` options and pick which layers to trace with the top-level `tracingChannel` option.

## Configure module options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lutejka/nuxt-otel'],
  nuxtOtel: {
    // Enable built-in OpenTelemetry SDK (Node.js only)
    instrument: true,
    // Enable the OpenTelemetry panel in Vite DevTools
    devtools: true,
  },
})
```

| Option       | Default | Description                                                            |
| ------------ | ------- | ---------------------------------------------------------------------- |
| `instrument` | `true`  | Adds a built-in `NodeSDK` that exports traces via OTLP on Node presets |
| `devtools`   | `true`  | Adds the OpenTelemetry panel to Vite DevTools in dev                   |

## Enable tracing channels

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  tracingChannel: {
    nuxt: true,
    h3: true,
    srvx: true,
    unstorage: true,
  },
})
```

Set `tracingChannel: true` to enable all channels, or `false` to disable all.
