## Prerequisites

- Nuxt `>= 4.5.0` for `nuxt.*` channels (`render`, `island`, `data`, `plugin`)
- Nuxt `>= 5.0.0` for `h3`, `srvx` and `unstorage` channels
- Node.js preset (`node-server`), `bun`, or the default Nitro preset for built-in instrumentation

## How to install

::code-group

```bash [pnpm]
pnpm add @lutejka/nuxt-otel
```

```bash [npm]
npm install @lutejka/nuxt-otel
```

```bash [yarn]
yarn add @lutejka/nuxt-otel
```

```bash [bun]
bun add @lutejka/nuxt-otel
```

::

## How to enable the module

Add it to the `modules` array in your Nuxt config:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lutejka/nuxt-otel'],
})
```

## How to verify installation

Start the dev server and look for the `Nuxt OTel devtools` box in the terminal:

```bash [pnpm]
pnpm dev
```

You should see the OTLP ingest URL and MCP server endpoint. Then open Vite DevTools and confirm the **OpenTelemetry** panel lists traces after you load a page.
