## Prerequisites

- Node.js `>= 22.15.0` (required by OpenTelemetry JS SDK 3.x)
- Nuxt `>= 4.5.0` for `nuxt.*` channels (`render`, `island`, `data`, `plugin`)
- Nuxt `>= 5.0.0` for `h3`, `srvx` and `unstorage` channels
- Node.js preset (`node-server`), `bun`, or the default Nitro preset for built-in instrumentation
- Optional: `@devframes/agentic` as a dev dependency for the MCP server

## How to install

::code-group

```bash [pnpm]
pnpm add @lutejka/nuxt-otel
```

```bash [npm]
npm install @lutejka/nuxt-otel
```

```bash [yarn]
yarn add @lutejka/nuxt-otel
```

```bash [bun]
bun add @lutejka/nuxt-otel
```

::

## How to enable the module

Add the module and enable at least one tracing channel in your Nuxt config:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lutejka/nuxt-otel'],
  tracingChannel: true,
})
```

Tracing channels are opt-in. If `tracingChannel` is unset, the module loads the SDK but registers no channel hooks, so no spans are created.

### Enable only some channels

Use an object to choose channels. Set the channels you do not want to `false`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  tracingChannel: {
    nuxt: true,
    h3: true,
    srvx: false,
    unstorage: false,
  },
})
```

Keys you omit from an object default to `true`, so set unwanted channels to `false` explicitly.

## What gets installed

The module adds three things to your app:

- Server composables for manual spans, metrics, and logs
- A built-in `NodeSDK` when `nuxtOtel.instrument` is enabled (intended for Node.js presets)
- An **OpenTelemetry** panel in Vite DevTools when `nuxtOtel.devtools` is enabled

## How to verify installation

Start the dev server:

```bash [Terminal]
pnpm dev
```

Look for the `Nuxt OTel devtools` box in the terminal. It prints the OTLP ingest URL. The MCP server line appears only when `@devframes/agentic` is installed; otherwise it shows `disabled`.

Open Vite DevTools, load a page, and confirm the **OpenTelemetry** panel lists traces. If the panel is empty, see [Troubleshooting](/reference/troubleshooting).

## Troubleshooting

### No traces in DevTools

- Confirm `tracingChannel` is set to `true` or explicitly lists the channels you need.
- Confirm `nuxtOtel.devtools` is not set to `false`.
- Load a page after starting the dev server so the panel has data.
- If you use a non-Node Nitro preset, set `instrument: false` and provide your own SDK. See [Instrumentation](/guide/instrumentation).

### MCP server shows disabled

Install the optional adapter and restart the dev server:

```bash [pnpm]
pnpm add -D @devframes/agentic
```

See [MCP Server](/guide/mcp-server#install-the-mcp-adapter) for the endpoint and client configuration.
